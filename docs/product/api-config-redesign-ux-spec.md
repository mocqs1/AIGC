# API 配置页重做 UX 与验收规范

状态：产品决策输入（MVP）  
日期：2026-08-28  
负责人：AIGC Studio Product OMP

## 目标

把现有按模块平铺的 API 配置弹窗重组为三个可扫描的业务区：

1. 图片生成模型
2. 视频生成模型
3. 智能混剪模型

分区只表达能力，不绑定供应商名称。新增或移除后端模块时，前端无需改代码即可显示、编辑和测试该模块。R2/存储配置不并入本页，沿用现有存储配置入口。

## 仓库依据与差距

- `api_server.py:100-107` 已有注册表 `MODULE_SPECS`，模块包含稳定 `id`、`name`、`category`、`capabilities`、默认 `model` 与 `options`；当前类别值为 `image`、`video`、`mix_planner`。
- `api_server.py:1483-1571` 已提供模块列表、单模块读取、原子保存、连接测试、模型发现接口。列表响应经过脱敏，只返回 `api_key_configured`，不会返回密钥。
- `web/src/App.jsx:279-380` 已有独立草稿、模块切换、Escape/Tab 焦点管理和模型发现；但当前通过 `selectedId === 'image.hermes'` 写死 Hermes 路径字段，左侧列表也没有业务分区。
- `web/src/api.js:19-44` 已封装模块列表、保存、测试和模型发现请求。
- 现有产品契约 `docs/product/intelligent-mix-api-config-contract.md` 要求模块互不覆盖、密钥写入且测试不持久化草稿；本规范沿用这些约束。

### 必须补齐的动态元数据

模块列表需要提供可直接渲染的字段描述（名称可本地化，但键必须稳定），建议形状：

```json
{
  "id": "video.example",
  "name": "Example Video",
  "category": "video",
  "capabilities": ["generate_video"],
  "api_url": "https://api.example.com/v1",
  "model": "video-model-v2",
  "enabled": true,
  "api_key_configured": true,
  "fields": [
    {"key": "api_url", "label": "API 地址", "type": "url", "required": true},
    {"key": "model", "label": "模型 ID", "type": "model", "required": true},
    {"key": "submit_path", "label": "提交路径", "type": "path", "required": false}
  ]
}
```

`fields` 仅描述 UI，不包含密钥或其他秘密值。字段类型至少支持 `url`、`model`、`path`、`text`、`number`、`boolean`、`select`、`secret`；`options` 中未出现在 `fields` 的键不在 UI 中展示。若后端暂时无法提供 `fields`，前端只渲染通用 API 地址、模型 ID、密钥、启用开关，不得按模块 ID 添加例外分支。

## 信息架构

### 页面结构

- 弹窗标题：**API 配置**；副说明明确“密钥仅发送给本地 AIGC 服务，不会回显”。
- 顶部使用三个业务区导航（标签或折叠分组均可）：图片生成模型、视频生成模型、智能混剪模型。计数显示该区模块数；没有模块时显示 0。
- 每区内按后端返回顺序（或 `order` 元数据）显示模块卡片。卡片展示：模块名称、稳定 ID（次要信息）、能力标签、启用状态、配置状态、当前模型名称/ID。
- 选中卡片后，在同一弹窗的详情面板编辑；切换分区或模块不得丢失其他模块草稿。
- 未知 `category` 不丢弃，进入“其他模型”兜底区并带原始类别提示；这保证后端扩展不会让配置入口消失。产品默认只对前三个类别显示正式中文标题。

### 模块详情

按 `fields` 顺序渲染表单。通用字段约定：

- API 地址：仅接受后端允许的绝对 HTTP/HTTPS 地址；前端提示不填写账号、密码、查询参数或片段。
- API Key：密码输入框；已配置时只显示“已配置，留空保持不变”，不能回显或写入浏览器存储。提供明确的“清除已保存 Key”复选框/操作。
- 模型 ID：支持手动输入。若模型发现成功，显示可选列表，同时保留手动覆盖能力；发现结果为空仍可手动保存。
- 非秘密 options：依字段类型显示；路径字段显示示例和相对路径约束，未知键不渲染。
- 启用此模块：关闭后仍保留配置，但在生成入口标记为不可用。
- 操作：测试连接、保存配置、取消。测试只验证当前草稿，不持久化；保存成功后只更新当前模块卡片状态。

## 状态与反馈

| 状态 | 页面行为与文案要求 |
| --- | --- |
| 首次加载 | 显示弹窗骨架（分区标题、卡片和详情字段占位）；控件不可提交。加载失败显示“无法加载 API 模块”，提供“重试”，保留关闭按钮。 |
| 空注册表 | 三个分区仍显示，分别显示“暂无已注册的图片/视频/智能混剪模型”；不显示伪造的供应商或默认模块。 |
| 空分区 | 分区标题、0 计数和说明保留；不要自动跳到其他区。 |
| 未配置 | 卡片状态“未配置”，详情表单可编辑；生成入口不应误报为可用。 |
| 已配置 | 卡片状态“已配置”；API Key 输入保持空白。 |
| 测试中/发现模型中/保存中 | 仅锁定当前模块的相关操作并显示进度；其他模块可继续查看，避免整页不可用。 |
| 测试成功 | 当前模块状态“连接成功”，使用 `role=status` 通知；不改变其他模块状态。 |
| 测试或保存失败 | 在当前模块详情内显示稳定、脱敏的错误；保留草稿和之前有效配置，允许修正后重试。 |
| 模型发现失败 | 显示“无法发现模型，可手动输入模型 ID”；不得清空已有模型 ID，不得展示上游响应体或密钥。 |
| 保存成功 | 显示“配置已保存”，刷新当前卡片的状态/模型摘要；关闭后再次打开读取持久化值。 |
| 关闭有未保存草稿 | 关闭不提交；再次打开读取上次持久化值。若产品选择增加确认，应只在存在变更时确认。 |

## 动态数据与兼容性要求

- 前端分区映射只依赖 `category`（`image`、`video`、`mix_planner`）；模块数量、名称、ID、顺序、能力和字段来自 `/api/settings/modules`，禁止维护供应商数组或模块 ID 白名单。
- `capabilities` 用于能力标签和生成入口过滤；不能用模块名称推断能力。
- 所有保存/测试请求继续走本地 API；沿用 `api_key` 写入、`clear_api_key` 清除、空 key 保留旧值的语义。
- 模型发现调用当前模块的 `/models` 接口，返回的 `models` 仅作为选项；请求失败不得阻塞手动录入。
- 新模块加入或后端下发字段变化后，页面可在刷新后显示而无需发布新前端包。
- 旧 `/api/settings/hermes*` 路由继续兼容，但新页面只使用模块化路由。

## 响应式与可访问性验收

- 桌面端：分区导航、模块卡片、详情面板在一个视口内可辨识；详情过长时仅内容区滚动。
- 窄屏端：导航可横向滚动或改为下拉选择，表单单列显示，无水平溢出；操作按钮保持可见。
- 弹窗使用 `role="dialog"`、`aria-modal="true"`，标题通过 `aria-labelledby` 关联；关闭后焦点回到打开 API 配置的按钮。
- 分区导航使用 `role="tablist"`/`tab`/`tabpanel`（或等价原生控件），选中项有 `aria-selected`，面板有 `aria-labelledby`。
- 键盘：Tab 顺序为分区导航 → 模块卡片 → 当前详情字段 → 操作按钮；左右/上下箭头切换分区或模块，Home/End 跳到首尾，Enter/Space 选择；Escape 关闭弹窗。
- 每个输入控件有可见标签和程序化关联；密码字段有说明“留空保持不变”；错误通过 `role="alert"` 或 `aria-live="polite"` 关联到对应字段/模块。
- 状态不能只靠颜色表达：同时显示文本或图标及可访问名称；禁用模块和不可用按钮说明原因。
- 触控目标不小于 40×40 CSS px，文字在 320px 宽度下不截断关键状态或溢出容器。

## MVP 验收清单

- [ ] API 配置打开后始终显示三个业务区；区内模块完全由注册表驱动。
- [ ] 新增一个未知模块（任意新 ID）后，仅修改后端注册表即可在正确分区显示、编辑、测试、保存。
- [ ] 编辑模块 A、切换到 B、再返回 A，A 的未保存草稿仍在；关闭重开后草稿按约定丢弃且持久化值不变。
- [ ] 测试、保存、模型发现均为模块级 loading/error，不能覆盖其他卡片或泄漏上游错误/密钥。
- [ ] 模型发现有结果、空结果、失败三种可验证路径，三者均支持手动模型 ID。
- [ ] 启用开关、配置状态、连接状态在刷新后与后端一致；关闭模块不会删除配置。
- [ ] 320px 窄屏和桌面宽屏无水平滚动；鼠标和纯键盘均可完成编辑、测试、保存、取消。
- [ ] 通过自动化检查验证：对话框焦点陷阱与恢复、标签/状态 ARIA、Escape 关闭、箭头导航、错误播报。

## 假设、范围与风险

- 地理/部署：单机本地 AIGC Studio，无多用户权限；假设本地 API 可访问模块注册表。
- 时间：2026-08-28；本规范基于当前仓库代码和 `intelligent-mix-api-config-contract.md`，后端实现优先级高于旧文档。
- 置信度：高（现有路由、脱敏、模块类别和测试行为均有代码/测试佐证）；中（`fields` 元数据为建议接口，尚未在当前代码实现）。
- 风险：若继续按模块 ID 在前端写条件，新增供应商会再次需要发版；若后端未提供字段类型/标签，复杂 provider-specific options 只能以通用键值方式显示，易造成误填。
